# 鲸伴 SkyPet v0.2 · UI / 交互冻结规范

来源：captain 转述的用户会话《鲸伴 · 安卓桌宠 MVP》README（唯一产品真相源）；工作区根 README 属于其他项目。本规范供 Theme.kt 与 Android View 实现使用（本工程为纯 View 体系、禁用 Compose，见 CONTRACT §2.2）；浏览器预览只比比例，不参与编译。

## 1. 配色令牌

| Theme.kt 建议名 | 中文 | Hex | 用途 |
| --- | --- | --- | --- |
| MistBlue | 雾蓝 | `#B8D7E8` | 次级填色、开关轨道、角色头发 |
| DressBlue | 裙装蓝 | `#4778A8` | 主按钮、裙装、导航选中 |
| CreamWhite | 奶白 | `#FFF9EE` | 全局底色、气泡、卡片 |
| SoftPink | 浅粉 | `#F7E4E8` | 陪伴舞台、腮红 |
| SeaSaltBlue | 海盐蓝 | `#88BACB` | 地平线、封面海面 |
| InkBlue | 深蓝 | `#243E57` | 正文、图标描边、气泡文字 |
| MutedInk | 次级文字 | `#53697B` | 说明文字 |
| LineBlue | 分隔线 | `#D3E0E4` | 卡片边框 |
| PaperWhite | 白 | `#FFFFFF` | 白色按钮文字、卡片 |

浅色仅用于背景；文字使用深蓝/次级文字。选中同时提供文字和形状状态，不仅靠颜色区分。角色为原创简化鲸鱼娘：雾蓝头发、鲸尾发饰、裙装蓝裙子。

**配色规则（冻结 v2，取代旧表述）**：切换陪伴包时**内容与配色随包变化**（README「换的是内容和配色」），但**角色身份/轮廓不变**。角色颜色由当前插件 `look` 驱动，映射固定为：`hair=look.body`、`dress=look.accent`、`belly=look.belly`、`blush=look.glow`、`accessory 形状=look.accessory / 色=look.accent`、舞台/背景点缀=`look.accent`。`Theme.kt` 中的 SkirtBlue 等品牌令牌仅作**默认兜底**，不强制覆盖插件 look。**用户从相册导入的自定义形象优先级最高**：有导入图时整图覆盖矢量绘制，且不随包配色变化（独立设置）。

## 2. 布局、尺寸与文字

以393 × 852dp为比例参考，适配320dp及以上宽度；内容可纵向滚动，底部导航固定并避让系统手势区，使用 WindowInsets。CSS px只模拟逻辑尺寸，不等于设备物理像素。

| 元素 | 建议值 |
| --- | --- |
| 页面水平留白 / 模块间距 | 24dp / 20dp |
| 卡片内距 / 行间距 | 16dp / 12dp |
| 大卡片 / 小控件圆角 | 24dp / 14dp |
| 页面标题 / 分组标题 | 28sp semibold / 18sp semibold |
| 正文 / 注释 | 14sp / 12sp |
| 主按钮高度 / 字号 | 52dp / 16sp semibold |
| 列表行最小高度 / 点击热区 | 60dp / 48 × 48dp |
| 勾选图形 / 导航图形 | 20dp / 24dp，热区均扩到48dp |
| 滑块轨道 / 拇指 | 4dp / 20dp；触摸高度48dp |
| 底部导航高度 | 72dp + 安全区，标签12sp，图文间距4dp |
| 描边 / 阴影 | 1dp / 4dp elevation低透明蓝灰 |

支持系统大字号并允许换行；TalkBack读出控件名称、值、选中状态；焦点可见。减少动画开启时停止循环呼吸、浮动和眨眼。

## 3. 三页布局

### 陪伴页：小房间

标题「今天，也陪着你」。浅粉舞台约252dp高、28dp圆角，海盐蓝地平线在舞台高度约76%处，桌宠脚底站在线上。角色头顶奶白招呼语「今天也要记得喝水哦。」；右上显示真实开启状态。背景仅少量窗框/星星装饰，不抢角色焦点。

舞台下面严格依次：主按钮「开启陪伴」/「暂停陪伴」；桌宠大小滑块（72–144dp，默认108dp，显示实时数值）；显示范围（所有应用 / 只在游戏里出现，显示实际降级说明）；当前陪伴包（名称、简介与切换入口）。再下为每日任务清单。权限不足不能先显示已开启，授权返回重新检查。

### 陪伴包页

标题「给日常，换个风景」。卡片含原创简化风景封面（高112dp，海湾/云丘/星夜手绘SVG）、包名、简介、标签、「使用此包」或「正在陪伴」。禁止游戏截图/官方素材。海风来信、云间小憩、星夜漫游为原型示例名，正式包名/ID以技术契约为准。

选中卡片DressBlue边框与文字状态同步。选择立即更新首页/面板内容、招呼语、任务、舞台点缀色与角色配色（由 look 驱动，轮廓身份不变），不改变角色大小/陪伴方式。每日状态按本地日期+包ID+任务ID隔离，切回同包保留当日勾选，避免不同包串记录。

### 设置页

分组为「形象」「陪伴方式」「权限」「关于」。形象含当前鲸鱼娘预览、从相册换形象、恢复打包透明底 pet_whale.png；相册取消不改当前形象，加载失败提示原因。陪伴方式含安静陪伴、休息提醒（每45分钟）；权限行显示悬浮窗/使用情况访问真实状态并打开系统授权页面；关于显示鲸伴 SkyPet v0.2与本地陪伴说明。

修改即时生效、保存后不需重启；失败恢复原值并给出说明。权限不能用本地开关伪造已授权。预览中的权限为演示，不能实际申请Android授权。

## 4. 底部导航手绘路径

顺序为陪伴、陪伴包、设置。24 × 24 viewBox，2dp圆头圆角描边；选中填DressBlue实心，未选中fill=none、stroke=InkBlue描边。选中另有浅雾蓝胶囊底与文字状态，标签保持可读。三条原创路径可直接映射为 Android `Path`（View 体系）：

```text

拼块：M4 4 H9 C8 0 16 0 15 4 H20 V9 C24 8 24 16 20 15 V20 H15 C16 24 8 24 9 20 H4 V15 C0 16 0 8 4 9 Z
```

切页不重启悬浮服务，选中标签与图标同步；不可只提供图标。

## 5. 悬浮角色 / 面板 / 气泡

透明背景，无白色方块；默认108 × 108dp，72–144dp可调。首次位置在右侧中下部距边16dp；拖动只移动角色，释放限制在可用屏幕内并保存位置；拖动不得误判为单击。呼吸周期3.6s、scaleY 0.98–1.02，浮动2dp；眨眼间隔4–7s、闭眼120ms；点击笑约1s。动画不改变点击区域。

单击在角色右侧弹出小助手面板，间距8dp、宽220dp、圆角20dp、内距16dp。内容来自当前陪伴包，含每日任务、提醒状态、右上48dp热区的「×」收起按钮与「歇一会儿」。右侧空间不足翻转到左侧，两侧不足约束在屏内。「×」仅收起面板，角色继续陪伴。

「歇一会儿」切入休息卡片，显示久坐提醒「站起来伸个懒腰，让眼睛看看远处吧。」与「我歇好了」按钮；不等同于停止服务。休息中停止45min周期，点击「我歇好了」回到常规面板并重新计时。明确暂停服务由首页「暂停陪伴」执行。

点击同时冒一个不可触摸气泡：CreamWhite奶白底、InkBlue深蓝字、14sp、最大宽200dp、内距12dp、圆角16dp，尾巴指向角色，约3s消失；连续点击替换单个气泡。Android气泡窗口必须不可触摸，点击穿透，不占用摇杆/飞行按钮热区；面板仅占自己的交互区域，收起后不留透明拦截层。布局尽量避开游戏主要操作区，实际不遮挡需真机验证。

## 6. 交互状态约定

- 每日勾选按本地日期+包ID+任务ID存储；本地午夜/回到前台时比较日期并跨天重置，不只依赖24h定时器；时区变化使用新的本地日。预览提供「模拟跨天」。
- 只在游戏里出现使用UsageStats识别光遇前台，离开光遇自动隐藏。无使用情况权限退化为始终显示，显示「无使用情况权限，已退化为始终显示」；返回应用重查，授予后恢复所选模式。悬浮权限仍为独立前提，缺失时不能显示桌宠。
- 安静陪伴：不主动搭话，无主动气泡/声音/振动，点它才回应；到45min只更新面板内提醒状态，避免主动打断。退出安静后重新完整计时，不补发堆积提醒。
- 休息提醒：开启并持续陪伴45min提醒起身，然后进入下一周期。暂停服务、关闭提醒或进入休息取消当前周期；恢复后重新计时。后台恢复最多显示一次当前提醒，不补发多条；持续时长使用单调时钟，日期变化不影响计时。
- 设置即时生效并持久化；插件切换不改变形象，相册换形象只由用户显式触发。
- 原型使用内存演示状态，刷新恢复默认；「演示45min提醒」显式模拟到点，不执行后台计时或系统悬浮。
